# llm-atlas

「LLM 系列」飞书长文的 Markdown 版。全系列 65 篇，分四层加一卷索引：地基 12（原理与数学）、系统 22（训练、推理与部署）、工程 21（Agent、RAG、评测、安全）、场景 8（落到具体业务），索引卷 2（论文清单、效率全景图）。

正文在 [`book/`](book/README.md)，从总览 LLM-00 读起：第二节是全部文档的清单，标题可直接点开；各篇末尾有上一篇、目录、下一篇的链接。

在线阅读：<https://zyaochen.github.io/llm-atlas/>，带侧边目录、全文搜索和公式渲染。它由 `mkdocs.yml` 从 `book/` 生成，推送到 main 后自动发布；本地预览：`pip install -r docs-site/requirements.txt && mkdocs serve`。

## 和飞书原文的差别

- **编号有空缺**：第 49、60–63、66、72 篇是工作中的内部案例，没有收录，编号保留不动，所以文件名不连续。
- **配图是图片**：原文的画板导出为 JPEG（裁掉白边，宽度不超过 1600 px），图里的文字不能搜索、不能复制。图的替代文本取自画板标题。
- **附件没有收录**：LLM-04 原文附带的书籍 PDF 不在仓库里。LLM-04、LLM-09 是两本书的精读笔记，书的内容以原书为准。
- **公式**：行内公式写成 GitHub 的 `` $`...`$ ``，独立公式用 ```` ```math ```` 代码块，GitHub 和在线版都能渲染。
- **统计数字以原文为准**：总览里的篇数、字数、图数写于不同时间，个别地方前后不一（例如系列地图说 64 篇、配图标题说 58 篇），这里照原文保留，没有改。

## 在线版的构建期处理

源文件不改，只在构建时调整，代码在 `docs-site/hooks.py`，单测 `python3 -m unittest discover -s docs-site`。和其他系列仓库一样，它把 GitHub 写法的行内公式转成 KaTeX、给紧跟段落的列表和表格补空行；本仓库另有两处：

- 侧边栏按标题里的层级分组，组名和顺序写在 `mkdocs.yml` 的 `extra.nav_stages`。
- Material 自带的 lunr 在给 TokenSet 状态生成键时，标签和子节点 id 之间没有分隔符，索引大了以后会合并两个不同的状态，三个字以上的中文查询会报错、搜不到结果。构建后给搜索 worker 补上分隔符；Material 升级后这段代码找不到时构建直接失败。
